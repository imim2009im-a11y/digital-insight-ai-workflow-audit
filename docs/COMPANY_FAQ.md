# Company FAQ | أسئلة الشركات

## بالعربية

### ما الذي نفعله؟
نراجع سير عمل واحداً متكرراً داخل المنشأة، نوثق وضعه الحالي، نقيس خط الأساس، ثم نحدد هل توجد فرصة تستحق تجربة أتمتة صغيرة وقابلة للرجوع.

### هل هذه خدمة مدفوعة الآن؟
لا. المستودع العام حالياً في وضع **Validation Only**. لا يوجد Checkout ولا تحصيل ولا وعد بنتيجة مالية.

### هل تحتاجون دخولاً إلى أنظمتنا؟
ليس في مرحلة التحقق الأولى. نبدأ بوصف عام للعمل ومقاييس تشغيلية غير حساسة. أي وصول تقني لاحق يحتاج نطاقاً مكتوباً وموافقة صريحة وحدود صلاحيات واضحة.

### ما البيانات التي لا يجب إرسالها؟
لا ترسل:
- كلمات مرور أو OTP،
- مفاتيح API أو Tokens،
- بيانات بطاقات،
- نسخ قواعد بيانات،
- ملفات عملاء أو موظفين حساسة،
- بيانات هوية أو معلومات صحية غير لازمة.

### ماذا نستلم من التحقق؟
- خريطة أولية لسير العمل،
- المقاييس التي يجب جمعها،
- فرضيات فرص الأتمتة،
- مخاطر وقيود،
- قرار أولي: STOP / ITERATE / PILOT.

### هل تضمنون توفيراً أو إيراداً؟
لا. لا توجد نسبة ROI أو توفير أو زيادة إيراد بدون Baseline وقياس فعلي.

## English

### What do you do?
We review one repetitive workflow, document the current state, define a measurable baseline, and determine whether a small reversible automation pilot is justified.

### Is this a paid service now?
No. The public repository is currently **Validation Only**. There is no checkout, payment collection, or guaranteed financial outcome.

### Do you need access to our systems?
Not for the first validation conversation. We begin with a high-level workflow description and non-sensitive operational metrics.

### What should never be shared?
Do not send passwords, OTPs, API keys, payment data, database dumps, or sensitive customer/employee data.

### What is the output?
A workflow map, baseline plan, ranked hypotheses, risks, and a STOP / ITERATE / PILOT recommendation.
