# Engagement Process

## Stage 0 — Fit check
Goal: confirm there is one repetitive workflow worth measuring.

Output:
- workflow owner,
- business objective,
- frequency,
- rough time/volume,
- obvious exclusions.

Decision: STOP or continue.

## Stage 1 — Baseline
Define the current state before proposing technology.

Required:
- cases per week/month,
- average handling time,
- waiting time where relevant,
- rework/error rate if measured,
- direct tool/labor cost if available.

No ROI claim is allowed without this step.

## Stage 2 — Workflow map
Document:
- trigger,
- actors,
- systems,
- handoffs,
- inputs/outputs,
- approvals,
- sensitive-data boundaries.

## Stage 3 — Opportunity ranking
Each automation candidate is scored on:
- measurable impact,
- simplicity,
- reversibility,
- data quality,
- privacy/security risk,
- failure consequence,
- human-review feasibility.

## Stage 4 — Controlled pilot
A pilot must:
- use the smallest useful scope,
- retain human approval where material,
- have a rollback path,
- define success metrics before execution.

## Stage 5 — Measure and decide
Compare against baseline using the same metric definitions.

Decision:
- STOP,
- ITERATE,
- SCALE.

Scale is never the default.
