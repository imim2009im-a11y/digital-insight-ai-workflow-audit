# Synthetic Sample Report

**Synthetic example only — not a real client, not a case study, and not evidence of savings.**

## 1. Scope
Workflow: weekly product-content update for a hypothetical online retailer.

## 2. Synthetic baseline
- 80 items/month
- 12 minutes handling/item
- 16 labor hours/month
- 8% rework rate

## 3. Bottleneck hypothesis
Manual copy/paste and repeated formatting may be creating avoidable handling time.

## 4. Candidate pilot
Assist a human operator with:
1. structured field extraction,
2. first-draft copy generation,
3. consistency checks,
4. human approval before publishing.

## 5. Guardrails
- no autonomous publishing,
- no customer data,
- no payment data,
- test on synthetic/product catalog data first,
- revert to manual workflow at any time.

## 6. Success metrics
- handling minutes/item,
- rework rate,
- approval rejection rate,
- correction count.

## 7. Decision rule
Scale only if measured quality is acceptable and the agreed metric improves materially versus baseline.
